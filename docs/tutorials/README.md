# Tutorials

Learning-oriented. Follow one of these end to end, with a fresh build and the
synthetic example workspace, before touching a real deployment.

- [Quickstart](quickstart.md) — build the CLI, validate the synthetic
  workspace, and create a private workspace of your own.
- [Guía rápida](quickstart.es.md) — the same tutorial, in Spanish, extended
  through provisioning and day-to-day operation commands.
