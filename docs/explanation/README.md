# Explanation

Understanding-oriented. Why the engine is built the way it is, and what shape
it's in. Not needed to complete a task — read these when you want the
background.

  the responsibility split between Terraform/CLI/reconcilers, the mesh
  backplane, and the apply sequence.
- [Implementation status](implementation-status.md) — a milestone-by-milestone
  account of what's built, in what order, and why.
- [M0 review packet](M0-REVIEW.md) — the acceptance evidence recorded when
  milestone M0 closed.
- [Decisions](decisions/) — numbered architecture decision records (ADRs) and
  [open questions](decisions/OPEN-QUESTIONS.md) deliberately left unanswered.
